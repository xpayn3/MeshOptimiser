# MeshOptimiser v0.32.0 (Idrija)

Notes: leave them on the model, answer, edit and resolve them, and send the scene with everything inside.

## New

**Notes on the model.** Press N and click a spot: a numbered pin stays on that part, and follows it when the part moves, is hidden or the view is exploded. A small picture of the view the note was written from is kept with it. A note can also be about the selected part or the whole scene. Each note has a tag (Info, Question, Issue, Idea), can be given to somebody, and is a conversation: anyone can reply, edit or delete any message, resolve the note or open it again.

**Every change carries a name.** Before the first note, reply or edit the app asks you to type your name; it is remembered and you can change it in the Notes card. Every message shows who wrote it and when. An edited message says who edited it and keeps what it said before. A deleted message stays as a line saying who deleted it, and can be brought back. Each note has a History that lists everything that happened to it. Nobody signs in, so a name is what the person typed.

**Saved with the scene.** The notes go in the scene file (Save scene has Include the notes), together with when each person last saved, so New to me shows what somebody else changed since. Opening the scene opens the notes. Export never writes notes, and other programs open the scene as an ordinary GLB.

## Around the app

**The Notes card** in the right-hand column lists the notes with filters (Open, All, Resolved, New to me, Mine, Deleted), search and sorting. A click flies the camera back to the view the note was written from. The pop-up has next and previous, Move the pin, Use the view now as this note's view, Copy as text and Delete the note.

**Bring in notes from another copy.** When two people worked on their own copies of one scene, Bring in notes takes the other saved scene and joins the notes. New notes are added, replies, edits and resolutions are put together, the later change wins where both changed the same thing, and nothing anyone wrote is lost. Doing it twice changes nothing.

**A report anyone can open.** Report writes the notes as one HTML page with the pictures, every message, who edited what and the history. Copy puts them on the clipboard as text.

Every change to the notes is one Undo step, and the commands are in the search.
